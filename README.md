## 개요 및 개발동기

###  프로젝트 개요
> 원자재 입고부터 생산, 품질검사, 완제품 출고까지의 **전 공정을 실시간으로 관리/통제**할 수 있는 MES 시스템을 구현하였습니다. 
> 라면 생산 전 공정에 대한 **모니터링과 작업지시 관리**가 핵심 기능이며, 생산 실적과 불량률을 **실시간으로 수집/분석**할 수 있게 구현하였습니다.
> 주문/생산/품질/자재 관리 흐름을 하나의 시스템으로 통합하여 **생산 효율을 높이는 것**이 주 목적입니다.

- **Node.js** 기반 서버, **Vue.js** 프론트엔드, **MariaDB**를 이용한 실시간 데이터 처리 및 저장

###  개발 동기
- 라면 생산 공정은 원자재 입고부터 출고까지 단계가 많고, 공정 간 데이터 단절이 발생하면 생산 지연이나 품질 문제 야기
- 수기 관리나 분산된 시스템으로는 실시간 현황 파악과 즉각적인 의사결정에 한계가 있다고 판단
- 전 공정을 하나의 MES 시스템으로 통합하여 현장 데이터를 실시간으로 수집·관리하고, 생산과 품질을 동시에 통제할 수 있는 환경을 구축하고자 개발

### 기대 효과
- 생산효율 향상 : 주문·생산·품질·자재 관리가 하나의 흐름으로 연결되어 공정 간 **불필요한 대기와 오류 감소**
- 실적 파악 : 모든 공정 흐름을 데이터화 하여 **생산 실적 파악 용이**
- 문제 즉각 대응 : 생산 현황과 실적, 불량률을 실시간으로 파악할 수 있어 **문제 발생 시 즉각 대응**

## 느낀 점

- MES가 단순한 프로그램이 아니라 **운영 효율을 좌우하는 핵심 도구**임을 알게 됨.
- **현장 요구사항을 시스템으로 정확히 구현하는 것**의 중요성을 체감함
- 생산 라인의 공정 흐름 및 **MES 프로그램의 데이터 흐름**을 이해함.
