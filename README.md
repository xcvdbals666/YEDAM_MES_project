# YEDAM_MES_project
git merge 순서 : 다정 -> 지원 -> 정화 -> 유민 -> 정우 -> 진환 -> 영진 -> 현우
> commit 메시지 : 이름 이니셜_날짜_변경사항 ex) HYM_260119_수정

## 전체 작업 & Merge 흐름 정리

### 1️. 작업 전 (dev 최신화)
1. **dev 브랜치**를 선택합니다.
2. dev 브랜치에 **pull 받을 내용이 있으면 먼저 pull** 합니다.
3. 이후 **본인 브랜치로 이동**합니다.
4. **merge into**를 눌러 **dev 브랜치의 변경사항을 본인 브랜치에 머지**합니다.  
   (항상 dev를 기준으로 최신 상태 유지)

---

### 2️. 작업 진행

5. **작업은 항상 본인 브랜치에서 진행**합니다.
6. 작업이 모두 끝나면 **commit → push**까지 완료합니다.

---

### 3️. Pull Request & Merge

7. **Pull Request(PR)**를 생성합니다.
8. PR의 **대상 브랜치는 반드시 `dev` 브랜치**로 선택합니다.
9. **충돌이 없으면 그대로 merge**합니다.  
   (충돌이 있으면 해결 후 다시 확인)

---

> 최종 요약  
> **dev 최신화 → 내 브랜치에서 작업 → commit/push → dev로 PR → 문제 없으면 merge**
